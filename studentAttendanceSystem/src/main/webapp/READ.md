Student Attendance Management System

Project Overview

The Student Attendance Management System is a web-based application developed to manage student records and attendance efficiently.

It provides a simple interface to add, update, manage student details and maintain attendance records.

Technologies Used

- Frontend: HTML, CSS, JSP
- Backend: Java, Servlets
- Database: MySQL
- Database Connectivity: JDBC
- IDE: Eclipse
- Version Control: Git & GitHub
- Server: Apache Tomcat

Key Features

- Student Login
- Add New Students
- Manage Student Records
- Update Student Details
- Mark Student Attendance
- View Attendance Records
- MySQL Database Integration

Project Architecture

The application follows a basic web application architecture:

1. User interacts with the frontend.
2. Java Servlets handle incoming requests.
3. JDBC connects the application to MySQL.
4. MySQL stores student and attendance information.
5. JSP displays dynamic data to users.

DevOps & Cloud Deployment Scope

The project is maintained using Git and GitHub for version control.

Planned Improvements:

- Deploy the application on AWS EC2.
- Configure Apache Tomcat for application hosting.
- Use Amazon RDS (MySQL) for database hosting.
- Store database credentials securely using environment variables.
- Implement Jenkins for CI/CD automation.
- Monitor application infrastructure using Amazon CloudWatch.

Learning Outcomes

- Understanding Java-based web application architecture.
- Working with MySQL database connectivity using JDBC.
- Understanding Git and GitHub version control.
- Learning application deployment and AWS cloud integration concepts.
